# `native/` — the `.dll` broken down

Three layers of the same 1.93 GB file. Everything here is generated by
`tools/dump_native.py`, `tools/devirt_native.py` and `tools/dump_heap_members.py`
from a static read of the image; nothing was executed.

## `dump/`

| file | contents |
|---|---|
| `pe.txt` | headers, data directories, nine sections with entropy, export kinds, function counts per section |
| `exports.tsv` | 534 named exports: `rva`, name, section, kind (`jni`, `libjava`, `centrypoint`, `graal`, `astralis`, `other`) |
| `imports.tsv` | 404 imports from 22 DLLs with hint and IAT slot |
| `summary.txt` | the six numbers that matter |

The two `astralis` exports are `serenity_client_bind` and `serenity_client_start`
at `0x1e43d00` and `0x1e440e0` — the client's own isolate entry points.

## `devirt/`

| file | contents |
|---|---|
| `devirt_summary.txt` | call sites per encoding, resolved/unresolved, edge count |
| `callgraph_top.tsv` | the 20,000 most frequent caller→callee edges |
| `import_calls.tsv` | the 404 imports ranked by number of call sites |
| `iat_sites.tsv` | every import call site: `dll`, `function`, `caller`, `caller_name`, `site` |
| `hot_functions.tsv` | the 60 functions with the highest in-degree |
| `vmp0_summary.txt` | `.vmp0` decoded: 294,735 records, table extent, length histogram, mnemonic histogram |
| `vmp0_chunk_sigs.tsv` | the 500 most common chunk openings, as `first_insn` + 8 raw bytes |

`.vmp0` is not a bytecode VM. It is a `{u32 rva, u16 length}` table of 294,735
records over a 6.6 MB band of in-place-mutated x86, plus its own code. The
history of that claim, with the numbers that support it, is in
`../docs/analysis/NATIVE_DUMP.md`.

## `decompiled/`

328 functions passed through Hex-Rays, sorted by what they are: `entry/` (the
two client entry points), `jdk/` (264 JNI functions, the whole
`sun.security.mscapi` family among them), `runtime/` (30 highest in-degree),
`samples/` (24 unnamed `.text` functions) and `vmp0/` (8 chunks that all
decompile to a `JUMPOUT` five bytes into themselves). `index.tsv` carries
`group`, `rva`, `label`, `size`, `lines` per file. Generated by
`tools/carve_window.py` + IDA + `tools/decompile_native.py`; see the folder's
own `README.md`.

## `bodies/`, `registry/`

Earlier pass over the Java-layer natives: 16 recovered C bodies of the small
bytecode interpreter in `dev/opalV2/x64-windows.dll`, and the symbol tables the
bodies were reconstructed from. See `../docs/analysis/DEVIRTUALIZATION.md`.

## Regenerate

```bash
python tools/dump_native.py    work/exe/Runtime/astralis.dll native
python tools/devirt_native.py  work/exe/Runtime/astralis.dll native
```

`dump_native.py` and `dump_heap_members.py` are stdlib only. `devirt_native.py`
uses capstone when installed and falls back to raw byte signatures when it is
not; the counts do not change.
